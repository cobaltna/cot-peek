# 让你看懂模型英文思维链

**AI 用英文思考。这颗小球把它的思考实时翻成中文。**

ZCode 每一步动作之前都会先写一段思维链。那段文字全是英文，动辄几千字，等你读完，AI 已经又做完三件事了。思考小窗住在屏幕边缘，是一颗深色的圆球。AI 每想完一轮，中文译文半秒内就出现在悬浮窗里，扫一眼就懂，手上的工作不用停。

![思考流翻译](screenshots/thinking.png)

## 快，而且安静

- 写入到出译文实测 0.05 到 0.5 秒。靠的不是轮询，是目录变更通知，文件一动它就醒。
- 几万字的长思考切成千字段，三路并发，逐段上屏，不用干等整轮翻完。
- 空闲时 CPU 实测 0.00%。所有等待都发生在内核里，不空转、不起子进程。
- 收起成球即暂停，零翻译开销，再展开自动补上错过的部分。

## 翻得像样

- 三个免费接口自动降级：火山翻译网页版，cn.bing.com，MyMemory。哪个快用哪个，全挂了保留原文标红，稍后一键重试。
- 代码块、URL、文件路径、常见术语先占位再翻，翻完原样还原。`cot_peek.py` 不会被翻成别的字。
- 复制一段英文，1 秒内出中文。窗口收着的时候不监听剪贴板。

![划词翻译](screenshots/clipboard.png)

## 不添乱

- 纯外部读取。只看 ZCode 的 rollout 文件和进程快照，不写入，不注入，不碰模型上下文。
- 窗口四条边都能拖拽改大小，位置和尺寸都记得。
- ZCode 退出，小球即时跟随退出，靠的是进程句柄等待，不是定时轮询。
- 纯 Python 标准库加 tkinter，单文件一千三百行，全部逻辑一目了然。

## 安装

**从 ZCode 插件市场装**：打开 设置 → 插件管理 → 发现，点 + 添加市场，输入 `cobaltna/cot-peek`，安装「思考小窗」。然后对 ZCode 说一句「启动思考小窗」，或运行 `/cot-peek:start`。

**直接跑**：

```powershell
git clone https://github.com/cobaltna/cot-peek.git
pwsh cot-peek\plugin\install.ps1
```

装完约 1 分钟内小球出现。不想装计划任务，双击 `plugin\start-cot-peek.bat` 也能立即体验。

要求：Windows 10/11，一份带 tkinter 的 Python 3。官网安装包默认满足。

## 它是怎么工作的

ZCode 每完成一次 API 往返，就把这一轮思维链追加写进 `~/.zcode/cli/rollout/` 下的会话文件。思考小窗用 ReadDirectoryChangesW 盯住这个目录，文件一有动静立刻读增量、按句切段、并发翻译、逐段上屏。退出检测对 ZCode 根进程句柄做 WaitForSingleObject，进程一结束立刻跟随退出，全程零轮询。
